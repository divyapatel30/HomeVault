# HomeVault Wireframes

The MVP UI should be simple, secure, and easy to explain.

## Suggested wireframe screens

### 1. Landing page
- Brand title: HomeVault
- Short project description
- Links to Login and Sign Up

### 2. Login page
- Email field
- Password field
- Login button
- Link to sign-up page

### 3. Sign up page
- Full name
- Email
- Password
- Create account button

### 4. Dashboard
- Family members panel
- My Documents section
- Shared with me section
- Expiry alerts widget

### 5. Document upload modal or page
- Document file picker
- Title and description
- Category selection
- Owner name / person
- Optional expiry date
- Access mode selector
- Save button

### 6. Family member view
- List of family members
- Document cards for that member
- Download/view actions for allowed files

### 7. Document details
- File metadata
- Access level
- Ownership
- Download button
- View-only notice for other users

## UI principles

- Keep privacy visible and explicit
- Make sharing choices clear
- Provide easy document search and filters
- Keep the layout responsive and clean
- Avoid exposing private documents unless access is granted

## Deliverable expectation

Wireframes should be lightweight, readable, and aligned with the MVP focus: secure family document sharing with controlled permissions.
